YOLOv8 Object Detection · Flask · Docker · Data Visualization

基於 YOLOv8 之海洋廢棄物影像偵測與分類統計系統

本系統以海洋廢棄物影像為分析對象，整合 Flask 網頁介面、YOLOv8 物件偵測、 OpenCV 影像標註、Pandas 資料整理與 Matplotlib 視覺化圖表， 讓使用者能上傳影像並取得廢棄物偵測結果、分類統計與累積分析資料。

開始影像分析

AI 物件偵測

使用 YOLOv8 模型分析上傳影像，偵測圖片中可能出現的廢棄物物件， 並取得類別、信心分數與座標資訊。

影像結果標註

透過 OpenCV 將偵測框、類別名稱與信心分數標示於圖片上， 讓辨識結果能以直觀方式呈現。

分類統計分析

使用 Pandas 將偵測結果整理為 CSV，並以 Matplotlib 產生分類數量、 圖片偵測數與信心分數分布圖。

Image Upload

上傳圖片進行影像分析

請上傳海洋廢棄物相關影像，系統將進行物件偵測、結果標註與分類統計。

拖曳圖片到這裡

支援 JPG、JPEG、PNG 格式，也可以點選下方按鈕選擇檔案。

尚未選擇任何檔案

本系統已完成影像上傳、物件偵測、結果標註、CSV 紀錄與統計儀表板流程。

若尚未放入海洋廢棄物資料集訓練後的 best.pt， 系統會先使用 yolov8n.pt 進行流程測試； 後續可替換為專用模型以提升海洋廢棄物辨識準確度。

統計儀表板會根據已分析過的圖片結果，自動累積內容並產生圖表。
