專題說明

本頁整理專題動機、系統功能、技術架構、資料流程、限制與未來改進方向。

一、專題動機

海洋廢棄物會影響海岸環境、生態系統與海洋資源管理。傳統影像判讀多仰賴人工觀察， 不僅耗費時間，也較難快速整理成可分析的數據資料。因此，本專題嘗試以資訊工程方法， 將海洋廢棄物影像轉換為可標註、可統計與可視覺化的資料。

本系統以 YOLOv8 物件偵測為核心，結合 Flask 網頁介面、OpenCV 影像處理、 Pandas 資料整理與 Matplotlib 圖表視覺化，建立一套可上傳圖片、顯示偵測結果、 紀錄分析資料並呈現統計儀表板的海洋廢棄物影像分析系統。

二、系統功能

  • 提供使用者上傳 JPG、JPEG、PNG 格式影像。
  • 使用 YOLOv8 模型進行物件偵測與類別判斷。
  • 透過 OpenCV 將偵測框、類別名稱與信心分數標示於圖片上。
  • 將每次偵測結果紀錄為 CSV，包含圖片名稱、類別、信心分數與座標資訊。
  • 使用 Pandas 統計各類別數量、平均信心分數與累積分析紀錄。
  • 使用 Matplotlib 產生分類數量圖、每張圖片偵測數量圖與信心分數分布圖。
  • 透過 Flask Dashboard 呈現累積偵測結果與統計圖表。

三、系統流程

圖片上傳 → YOLOv8 偵測 → OpenCV 畫框 → CSV 紀錄 → 統計分析 → Dashboard 呈現

五、模型說明

本系統的核心辨識流程使用 YOLOv8 物件偵測模型。使用者上傳圖片後， 系統會將圖片送入模型進行推論，取得每個偵測框的類別、信心分數與座標， 再透過 OpenCV 將結果標示於圖片上。

若專案資料夾中已放入 models/best.pt，系統會優先使用自訂訓練模型。 若尚未放入 best.pt，系統會先使用 yolov8n.pt 預訓練模型進行流程測試。此設計能讓網站系統先完成與驗證，後續再替換正式模型。

六、限制與未來改進

目前系統已完成影像上傳、YOLOv8 推論、結果標註、CSV 紀錄與 Dashboard 統計流程。 若尚未放入自訂訓練的 models/best.pt，系統會先以 YOLOv8 預訓練模型進行流程測試。 由於預訓練模型並非專門針對海洋廢棄物資料訓練，因此在水下、模糊、遠距離或光線不足的影像中， 可能出現未偵測或誤判情形。

後續可使用公開海洋廢棄物標註資料集重新訓練 YOLOv8 模型，將塑膠瓶、保麗龍、罐子、 漁網、塑膠袋等類別建立為專用辨識類別，並將訓練完成的 best.pt 匯入本系統，以提升模型在海洋廢棄物影像中的辨識準確度。
