About Project

專題說明

本頁整理專題動機、系統流程、使用技術與未來改進方向。

一、專題動機

海洋廢棄物會影響海岸環境、生態系與人類活動。本專題希望透過資訊工程中的 影像辨識與資料分析方法，將原本需要人工觀察的海洋廢棄物影像，轉換成可統計、 可視覺化的數據資料。

二、系統功能

  • 使用者可上傳海洋廢棄物影像。
  • 系統使用 YOLOv8 進行物件偵測。
  • OpenCV 會在圖片上標示框線、類別與信心分數。
  • Pandas 會將偵測結果整理成 CSV。
  • Matplotlib 會產生分類數量與信心分數圖表。
  • Flask Dashboard 會呈現累積分析結果。

三、系統流程

圖片上傳 → YOLOv8 偵測 → OpenCV 畫框 → CSV 紀錄 → 圖表分析 → Dashboard 呈現

四、使用技術

Python
Flask
YOLOv8

GitHub Codespaces

五、限制與未來改進

第一版系統主要著重於完成影像上傳、模型推論、結果統計與網頁展示流程。 若尚未放入自訂訓練的 best.pt，系統會先以 YOLOv8 預訓練模型測試流程。 未來可使用海洋廢棄物影像資料集重新訓練模型，提升塑膠瓶、保麗龍、漁網、 罐子等類別的辨識準確度。
